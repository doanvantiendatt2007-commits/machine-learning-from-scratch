# Machine Learning From Scratch

## About Me

I'm **Doan Van Tien Dat**, a Robotics and Artificial Intelligence student at **Ho Chi Minh City University of Technology and Engineering (HCM-UTE)**, Vietnam.

I'm interested in Machine Learning and created this project to gain a deeper understanding of how Machine Learning algorithms work.

## About This Project

This is a personal learning project where I study and implement Machine Learning algorithms from scratch, inspired by **Scikit-learn**.

The purpose of this project is not to replace or compete with Scikit-learn, but to help me better understand the mathematical foundations, logic, and underlying principles of Machine Learning algorithms.

Each algorithm is independently implemented based on my understanding of its mathematical foundations and underlying principles.

My implementations may differ from Scikit-learn in terms of structure, functionality, and performance.

This project has no specific deadline. I simply learn and work on it whenever I have time, making a little progress each day.

I also preserve previous versions of my implementations to track how my understanding and approach to implementing algorithms evolve over time.
